# TaskFlow — App de Lista de Tareas con Inicio de Sesión

Aplicación web ligera y lista para usar creada con HTML, CSS y JavaScript puro.

## Características
- **Autenticación por usuario**: Registro de cuentas, inicio de sesión, cierre de sesión y botón de acceso rápido con cuenta de demostración.
- **Almacenamiento aislado por cuenta**: Cada usuario tiene su propia lista de tareas guardada automáticamente en `localStorage`.
- **Gestión completa de tareas**: Crear, completar, editar, eliminar, asignar prioridad (`Alta`, `Media`, `Baja`) y fecha límite.
- **Filtros y búsqueda**: Filtra por *Todas*, *Pendientes* o *Completadas*, busca por texto y limpia tareas completadas en un clic.

## Cómo ejecutarla
1. Descomprime el archivo `taskflow-todo-app.zip`.
2. Abre `index.html` directamente en cualquier navegador moderno (Chrome, Edge, Firefox, Safari) o sírvelo con Live Server.
